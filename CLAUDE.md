# Go60 layout aligned with my ZSA Voyager

Keyboard layout for a MoErgo **Go60**, built to match my **ZSA Voyager** layout so muscle memory carries between the two. The Go60 layout is a MoErgo Layout Editor JSON file; it is generated by a script, not edited by hand.

## Files

| File | What it is |
|---|---|
| `remap.py` | **Source of truth.** Builds the layout from the factory file. Edit this, then rebuild. |
| `Voyager-Aligned Layout (macOS).json` | Generated output. Import into the MoErgo Layout Editor, build firmware there, flash the `.uf2`. |
| `Factory Default Layout (macOS).json` | MoErgo's Go60 factory macOS layout. Input to `remap.py`; keeps the Magic and Factory layers and trackpad settings. |
| `Oryx_ The ZSA Keyboard Configurator.pdf` | Print of my Voyager layout (Oryx `R7Y9a`, https://configure.zsa.io/voyager/layouts/R7Y9a/latest/0). Icons don't survive text extraction; render pages to images to read them (macOS has PDFKit via `swift`; no poppler installed). |

## Rebuild

```bash
python3 remap.py "Factory Default Layout (macOS).json" "Voyager-Aligned Layout (macOS).json"
```

Then re-import the JSON into the Layout Editor. Any firmware `.uf2` built earlier is stale after a change.

## Go60 key index map (60 keys per layer)

- 0–11, 12–23, 24–35, 36–47: rows 1–4, left to right across both halves (row 1 = number row).
- 48–50: left bottom row (under the W, E, R columns), left to right.
- 51–53: right bottom row (under U, I, O), left to right.
- 54–56: left thumbs, outer → inner (56 is the innermost, nearest the middle).
- 57–59: right thumbs, inner → outer (57 is the innermost).

## Current layout

**Base (0)**
- Number row: Magic, 1–0, Backspace.
- Rows 2–4 match the Voyager: `` ` `` Q…P `\` / Tab A…; `'` / Shift Z…/ Shift.
- Shift keys: tap/hold = Shift, double-tap = Caps Word.
- Bottom row + thumbs, left to right: **Tab, Ctrl, Opt, Cmd, Space, Backspace | Esc, Enter, Cmd, Opt, Ctrl, Delete**.
  - Space = hold Raise, Backspace = hold Lower, Esc = hold Lower, Enter = hold Raise (`&lt`).

**Lower (1):** F1–F12 on the number row; Esc 1–0 Backspace; `! @ # $ % ^ & * ( )` Enter; `_ - + =` and `{ } [ ]`.

**Raise (2):** arrows on H J K L; Opt+arrows above; Cmd+arrows below; Cmd+Z/X/C/V under Z X C V; Esc / Backspace / Enter on the edges.

**Magic (3):** factory Go60 Magic layer (Bluetooth, RGB, bootloader, reset), except "Clear Bluetooth" moved from the top-left (where Magic is held) to the Z key.

**Factory (4):** unchanged factory switch-test layer.

**Mouse (5):** turns on automatically while the right trackpad moves (`&zip_temp_layer`, 500 ms). J K L = left / middle / right click, comma = Mission Control (Ctrl+Up), period = Spotlight (Cmd+Space).

## Layout Editor gotchas

- Custom behaviors (e.g. the Caps Word tap-dances) go in `custom_defined_behaviors` (inserted inside the keymap's root `/ { }`), and keys must reference them as `{"value": "Custom", "params": [{"value": "&td_lshft_cw"}]}`. A bare `{"value": "&td_lshft_cw"}` fails import validation.
- Trackpad processors live in `inputListeners`; `&zip_temp_layer` takes `[layer, timeout_ms]`.

## History and preferences

- I keep making mistakes with the thumb cluster and have iterated a lot on the bottom row + thumbs. Magic was on the innermost thumb keys, then the bottom row, now the top-left key. The current arrangement is being tried out on the keyboard.
- Open idea, not done: tune hold-tap timing on Space/Backspace/Esc/Enter (e.g. a custom hold-tap with `quick-tap-ms` and a balanced flavor) to cut misfires and let Backspace repeat when held. I chose to try the current placement first.
- Not ported from the Voyager: its trackball-only keys (CPI +/-, Aim, Drag Scroll).
- Prefer changes that could also be mirrored on the Voyager, so the two boards don't drift apart.
